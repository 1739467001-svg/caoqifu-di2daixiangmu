五主入口前端功能与生命周期验收
日期：2026-10-11
范围：本地前端；仅电脑。本记录不代表公网发布，也不代表实际浏览器视觉验收。

方法：在 Node 的隔离 VM 中运行真实 dist/app.js，用一次性 DOM/API 替身控制异步顺序。未访问服务器、数据库或用户浏览器存储，未写入生产/主预览资料。
脚本：review/five-views/test-ui-lifecycle.cjs
执行：node review/five-views/test-ui-lifecycle.cjs
结果：六组全部通过（含最终关闭面板时清理隐藏 DOM 的修改）。

1. 五入口和旧功能可达
   主导航仅：首页、作品、创作者、比赛、我的。
   原路由可达：我的作品、资料文件、参赛经历、我的动态、收藏、编辑个人资料、作品详情与历史版本、规则参赛建议、凭证草稿、登录、注册、隐私说明。
   旧地址兼容：portfolio、archive/posts、archive/profile、archive/bookmarks。

2. 私聊历史与内容安全
   缺失一个 API 消息窗口后，仍能通过历史分页补回；重复快照不产生重复消息或丢失已载入记录。
   同账号未发送草稿重渲染保留；聊天内容作 HTML 转义。
   待接受邀请和屏蔽状态不可发送；重置账号清除聊天、未读、发送状态和私聊草稿。

3. 消息辅助面板与旧地址
   消息及线程在辅助面板打开，背后的原主页面保持。
   原 #messages/:id 深链可以直接打开；首次进入时有真实首页作为背景。
   切到审核通知停止聊天轮询；关闭返回原主路由。
   可选完整聊天视图保留原聊天能力；再回面板时恢复原主页面，背景不留重复聊天输入区。

4. 加载中快速关闭
   在聊天列表请求未完成时关闭，迟到结果不能继续加载私人历史、标记已读或重新开始轮询。
   关闭会释放主页面的加载状态。

5. 轮询与可见性
   关闭时停止轮询；关闭后返回的旧结果不能覆盖未读数量。
   隐藏浏览器页不能标记私人消息已读。

6. 发帖草稿
   当前账号重新打开编辑页保留正文、类别及关联作品。
   换账号不能显示上一位创作者草稿；重置账号清空草稿。

实际浏览器应检查的原功能入口（由主代理负责）
   我的：作品/资料文件/参赛经历/我的动态，编辑资料、收藏、审核通知、HTML 与 JSON 导出、旧浏览器作品私密导入。
   作品详情：编辑与可见范围、附件关联上传下载删除、文字历史、删除作品。
   首页：三类筛选、展开帖子、回复、点赞、收藏、作者页和私聊、自己的帖子删除。
   发帖：类别、正文、关联自己的作品、预览、提交待审、错误时保留输入。
   对话：公开作者搜索、邀请、接受、发送、未读、历史分页、屏蔽、完整视图/收回、关闭与重新打开。
   原工具：规则参赛建议、HTML 作品页导出、未签名未上链的凭证草稿。

边界
   未重新测试后端全量逻辑；后台 API 和数据库不在本轮改动范围。
   审核通知当前展示作品及帖子状态，不包含回复审核状态。
   未做手机适配或手机验收；未新增短信、真实主办方确认、榜单或上链。
