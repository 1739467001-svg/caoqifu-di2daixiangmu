创作档案馆 · 独立本机页面

页面由三个文件组成，无需安装依赖：
dist/index.html
dist/workspace.css
dist/workspace.js

直接用浏览器打开 dist/index.html 即可使用。
当前本机预览地址：http://127.0.0.1:4189/

已支持：新建和拖动文件夹，保存消息、笔记和链接文本，选择不超过 512KB 的封面图片，并在本浏览器保存。
新建入口保留在左侧。点后弹出分步小窗，每次只问一件事：名称 → 保存什么 → 用途 → 是否放封面图片；最后才建到右侧画布。上一步保留填写内容，取消、关闭或按 Esc 不新建文件夹。文件夹设置也使用相同分步方式。
文件正文目前只提供示例。公开展示只有预览，没有真实发布；云端备份和链上存证尚未接入。
本浏览器保存不等于备份。更换浏览器或清除网站数据后，原有内容可能无法找到。

搬入主网站时，保留根节点 #archive-canvas-studio，并加载独立的 workspace.css 和 workspace.js。
需要把 CSS 中 body 和 :root 的样式改为只作用于弹窗容器，避免影响主网站。
